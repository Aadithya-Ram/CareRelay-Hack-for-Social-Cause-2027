# Security and responsible evaluation

CareRelay is a hackathon prototype. Use fictional patient/provider details and sample documents. It is not a certified clinical system or emergency service.

Do not disclose patient information, documents, passwords, session cookies or exploit details in a public issue. For a suspected vulnerability, use GitHub private vulnerability reporting if enabled, or contact the owner through an existing private channel. If no private channel is available, open a minimal issue asking for one without including the vulnerability or personal data.

The displayed `admin@123` password is for the isolated fictional judge demo. Loopback-only local testing must not be exposed as a public care network. Hosting requires secure operator provisioning and your own deployment configuration.

The [final audit](docs/FINAL-SUBMISSION-AUDIT-2026-10-24.md) records tested boundaries and known limits. Dependency scans are point-in-time checks, not guarantees against unknown vulnerabilities.
