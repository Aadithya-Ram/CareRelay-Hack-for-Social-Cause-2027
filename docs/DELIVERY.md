# CareRelay final delivery

Published URL: https://carerelay-dialysis-continuity.amplewand1.chatgpt.site

The site retains its existing public audience. CareRelay accounts and administrator access remain protected. Admin login opens the registered-account network; local and hosted databases are independent. Local testing admin@123 is accepted only on localhost for an existing coordinator; the public host requires the private coordinator password.

Final workflow: registration, membership approval, explicit dated care request, staff verification, manual/individual or bulk suggestion, admin approval, requested-provider confirmation. Membership alone never requests an arrangement.

Run Start-CareRelay.bat to build/start the local copy without clearing existing records. Source, guide, matching/role audit and version provenance are included in output/CareRelay-Submission.zip. output/Hosting-Receipt.json records the verified deployment; output/Final-Version.json pins the submission snapshot and SHA.

This is a packaged final project version, not an official event submission. Organizer eligibility, team details, registration and final upload remain the team's responsibility.

Demo assignment resources are now available in the registered-account care desk. Select a submitted appointment and use **Load demo hospitals & transport** to add three simulated hospitals, six machine slots and three vehicles near the pickup on its requested service day. See docs/DEMO-PROVIDERS.md for the demonstration steps.
