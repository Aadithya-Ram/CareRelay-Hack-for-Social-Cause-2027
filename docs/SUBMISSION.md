## Innovation statement

Scheduling and transport optimization already exist in research. CareRelay's prototype demonstrates the operational layer: timestamped evidence, human verification, atomic reservations, explicit acceptance, patient agreement, suitable funded transport, commitment-preserving repair and separate treatment-completion tracking. It tests interventions using the actual constraint model rather than an unsupported generated explanation.
